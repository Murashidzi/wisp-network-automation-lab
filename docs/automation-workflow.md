# Automated Subscriber Provisioning Workflow

This document describes the simplified automation pipeline used in this lab to simulate how new broadband subscribers could be provisioned automatically in a WISP environment.

The goal is to demonstrate how operational tasks can be integrated with infrastructure automation.


# Overview

When a new customer installation is completed, the provisioning system automatically creates the required subscriber credentials on the network access infrastructure.

Instead of manually creating PPPoE accounts on routers, the process can be automated through API-driven workflows.


# Provisioning Workflow

The automated provisioning sequence follows these steps:

1. Installation technician completes a new subscriber installation.

2. The installation platform records the service activation event.

3. A webhook or automation pipeline triggers the provisioning script.

4. The Python automation script communicates with the **RouterOS REST API**.

5. A new PPPoE secret is created with the appropriate service profile.

6. The subscriber device initiates a PPPoE session.

7. Bandwidth shaping and access policies are automatically applied.


# Example Provisioning Request

Example payload sent to the RouterOS API:
POST /rest/ppp/secret

```json
{
  "name": "sunway_house_402",
  "password": "AutoGeneratedAuthKey",
  "service": "pppoe",
  "profile": "20Mbps_Residential"
}```


# Benefits of Automation

Automating subscriber provisioning provides several operational advantages.

**Reduced Operational Overhead**
Manual configuration tasks are eliminated, reducing technician workload and minimizing configuration errors.

**Faster Service Activation**
Customers can begin using the service immediately after installation.

**Improved Consistency**
All subscribers are provisioned using standardized service profiles, ensuring consistent bandwidth enforcement and authentication policies.

**Integration with Monitoring Systems**
Provisioning events can be integrated with monitoring platforms to automatically track new subscriber sessions and network utilization.
